- **分层架构**：`core.rs` 封装底层 Vello 渲染器与全屏 Blit；`offscreen.rs` 管理 GPU 资源生命周期并执行 CPU 回读；`filter_backend.rs` 提供基于 WGSL 的 GPU 滤镜计算。
- **流式并行管线**：`render_pipeline.rs` 采用分块（Chunking）策略，将时间轴帧分配给多个 `OffscreenRenderer` 实例并行渲染，并通过有界通道（Bounded Channel）确保帧按序交付给编码器，实现内存占用与渲染吞吐的平衡。
- **零回读优化**：通过 `fullscreen_blit` 和 `PendingComposite` 机制，在 GPU 内部完成滤镜结果与主场景的合成，仅在最终输出或特定滤镜节点触发 CPU 回读，减少 PCIe 带宽压力。
- **模块化导出**：`encode` 子模块抽象了 GIF、静态图像及视频（FFmpeg）的编码逻辑，通过统一的 `ExportSettings` 与管线解耦。
