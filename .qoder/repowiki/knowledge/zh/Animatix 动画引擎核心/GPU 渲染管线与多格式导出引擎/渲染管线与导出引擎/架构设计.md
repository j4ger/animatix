- **分层架构**：模块分为底层 GPU 原语（`core.rs`, `fullscreen_blit.rs`）、中层渲染逻辑（`offscreen.rs`, `filter_backend.rs`, `transition.rs`）以及高层编排层（`render_pipeline.rs`, `encode/`）。
- **核心依赖**：以 `OffscreenRenderer` 为入口，封装 `wgpu::Device` 生命周期；通过 `RendererCore` 驱动 `vello::Scene` 到纹理的渲染。
- **GPU 计算管线**：`GpuFilterBackend` 利用 WGSL Compute Shader 实现高斯模糊和色彩矩阵变换，采用 Ping-Pong 纹理策略避免 CPU 回读。
- **并行导出模型**：`render_pipeline.rs` 实现了生产者-消费者模型，将帧渲染任务分块至多线程，并通过有界通道（Bounded Channel）保证输出帧的严格时序性。
- **接口边界**：通过 `mod.rs` 暴露统一的导出函数（如 `render_video_timeline`），内部屏蔽了复杂的 GPU 同步与编码器（ffmpeg/rsmpeg）交互细节。
