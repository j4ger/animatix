- **入口与生命周期**：`runtime.rs` 定义了 `AnimatixApp` 结构体并实现 `eframe::App` trait，负责初始化 WGPU 渲染上下文、音频引擎及主题配置。
- **命令驱动架构**：采用集中式命令模式，`commands.rs` 定义了 `ShellAction`（包含领域命令、视图动作和拖拽事件），通过 `command_bus.rs` 在面板与 Shell 之间传递。
- **文档控制层**：`document_controller.rs` 封装了对 AST 的原子操作（如创建/删除 Actor、关键帧编辑），将 UI 意图转化为源码变更并触发增量重建。
- **持久化与布局**：`persistence.rs` 利用 RON 格式序列化工作区布局（基于 `egui_tiles`）和应用状态；`file_tree.rs` 负责文件系统遍历与缓存。
- **设计系统**：`design_tokens.rs` 作为单一事实来源，统一定义了深色主题的颜色常量、间距比例和排版规范，确保 UI 视觉一致性。
