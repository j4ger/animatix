- Overlay modules implement a public `*_ui(&mut self, ui: &mut egui::Ui)` method on `GuiShell` that handles backdrop rendering, escape-key closing, and the main window layout.
- Modal dialogs consistently use a semi-transparent backdrop (`overlay_backdrop()`) and capture clicks to close the overlay when not in a running state.
- Action-triggering widgets (buttons, menu items) push `ShellAction` or `Command` variants into an `ActionQueue` or execute them directly via `handle_action`.
- Settings and form inputs utilize custom layout helpers (e.g., `layout::labeled_row`, `settings_row`) to maintain consistent alignment and spacing across different dialogs.
