- **Extension-based Architecture**: Implements UI logic as methods on the `GuiShell` struct (defined in the parent module), acting as a presentation layer that bridges user input with domain stores (`document_store`, `ui_store`, etc.).
- **Overlay Composition**: Comprises multiple self-contained overlay modules (`command_palette.rs`, `export_dialog.rs`, `find_replace.rs`, `insertion_palette.rs`, `settings.rs`, `shortcut_cheat_sheet.rs`) that render modal interfaces using `egui`.
- **Action Routing**: The `mod.rs` file serves as the central dispatcher, mapping `ShellAction` and `Command` enums to specific handler functions in sub-modules like `file`, `playback`, `scene`, and `actor`.
- **State-Driven Rendering**: UI state (e.g., dialog visibility, search queries) is maintained in shared stores, with each overlay module responsible for its own rendering logic and local state management (e.g., `ExportDialogState`).
