- **事件驱动架构**：采用 `CommandBus` 与 `ActionQueue` 实现面板（Panels）与核心状态（Stores）的解耦，确保 UI 交互逻辑与业务逻辑分离。
- **异步重建管线**：通过 `RebuildWorker` 在后台线程执行 AST 解析与场景编译，主线程通过令牌（Token）机制接收重建结果，避免界面卡顿。
- **双向同步机制**：`DocumentSession` 维护源码文本、AST 与时间轴索引（TimelineIndex）的一致性，支持代码编辑与可视化面板（如关键帧表）的实时双向更新。
- **模块化 UI 布局**：利用 `egui_tiles` 管理可停靠面板，通过 `WorkspaceBehavior` 统一处理跨面板的拖拽、选择与上下文菜单交互。
