- 采用标准的 Tree-sitter Rust crate 结构：`build.rs` 负责编译生成的 C 代码（`parser.c` 和 `scanner.c`），`src/lib.rs` 通过 FFI 暴露 `language()` 函数。
- 依赖方向清晰：构建时依赖 `cc` crate 编译 C 源码，运行时依赖 `tree-sitter` crate 提供解析接口。
- 资源嵌入：通过 `include_str!` 将外部的高亮查询文件（`highlights.scm`）直接嵌入二进制，确保查询逻辑与解析器版本一致。
- 外部源码引用：构建脚本指向同级目录下的 `../../tree-sitter-animatix/src`，表明 C 源码与 Grammar 定义位于 Crate 外部的共享目录中。
