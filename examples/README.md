# Animatix examples

[Browse the public AMX sources](../web/content/scenes/) or open them in the
[online Playground](https://amx.j4ger.dev/playground/).

The same files work with the native CLI and workbench.

```sh
animatix-gui web/content/scenes/first-move.amx
animatix image web/content/scenes/insertion-sort.amx --time 7.6 --output frame.png
```

See [the content catalog](../docs/content-catalog.md) for publication and test
fixture ownership.
