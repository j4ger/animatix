# Probe: indexed reactive assignment no longer falls back with a warning

Status: resolved.

## Intent

A real sorting visualizer wants bars generated by `for`, then driven per-frame
with indexed targets like `bar[i].scale` inside `always`.

## Minimal Repro

See `repro.amx`.

```animatix
always {
  for i in {0, 1, 2, 3, 4} {
    bar[i].scale = 1.0 + 0.05 * sin(t * 2.0 + i)
  }
}
```

## Expected DSL

`bar[i].scale = ...` should be a first-class reactive assignment.

## Resolution

The bytecode VM now compiles `AssignIndexed` into `WriteOverrideIndexed`,
resolving `{base}__{index}` at frame time. `animatix check` on the repro now
reports no `ModifierCompilationError`.

## Regression coverage

- `vm_indexed_override_compiles_and_matches_ir` verifies bytecode/IR parity.
- The repro remains as a dogfood regression fixture.
