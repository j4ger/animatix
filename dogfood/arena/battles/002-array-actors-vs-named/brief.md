# Dogfood Project Brief

## Content Goal

Present five numbered cards in a row. They enter left to right, then all lift
up together with a stagger. Same visual timing in both variants.

## Audience

A language designer comparing generated indexed actors with hand-named actors.

## Scenes

One scene, no scene transition.

## Constraints

- Target resolution: 1280x720.
- Visual style: `editorial-dark`.
- Five cards, each 160x90.
- Same relative timing in both variants.
- Grammar features under test: `for`-generated array actors, indexed targets,
  hand-named actors, `stagger`, and property assignment.
