# Animatix Planning Docs

This directory keeps planning documents inside the repository so they are visible
to every contributor and clone.

- [eparts-refinement-roadmap.md](eparts-refinement-roadmap.md): current detailed
  roadmap for the `eparts` widget/token framework. The short, canonical list of
  remaining work is `docs/roadmap.md`.
- [archive/](archive/): historical implementation plans and feasibility studies.
  Archive files are kept for context but are not current truth. Some may describe
  completed work, use stale line numbers, or predate later refactors.

Update `docs/roadmap.md` for current work. Archive a plan here when its active
items have been moved into the roadmap or completed.
