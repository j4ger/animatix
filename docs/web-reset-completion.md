# Web content reset: completion boundary

This pass finishes the editorial disposition of the former public collection;
it does **not** claim that every old source has been rewritten or corrected.

## Public content

- Five independent stories: One Rule, When Waves Meet, Same Words, Move the Basis,
  and Make Room. The last two replace broad matrix/sorting decks with focused,
  mathematically and algorithmically explicit stories.
- Six sequential lessons remain the beginning-to-end learning route.
- Four intent-oriented techniques teach reveal, focus, stagger and attached labels.
- Playground opens and downloads the same canonical sources used by the pages.

## Former public collection

All nine IDs are explicitly accounted for in `web/app/src/lib/legacy-works.ts`.
Compatibility pages explain the decision and offer a current route. Historical
AMX and assets remain available for imports/tests, but old HTML/JS/CSS are not
silently distributed as a competing public site. Source links identify a fixed
historical revision and warn that the old examples are not reference lessons.

This deliberately retires broad Transformer/topology/hash explanations rather
than pretending that a superficial visual refresh fixes their semantic gaps.
Epicycles remains archived; When Waves Meet is an alternative explanation of a
relationship, not a replacement Fourier course. Gradient's experimental source
is preserved without promising that all its legacy chapters were reviewed.

## Correctness contracts

- Shear: one `k` drives all geometry, fixed grey reference, equal coordinate scale.
  Area preservation is not presented as length preservation.
- Insertion sort: fixed input `[4, 2a, 5, 2b, 3]`; eight key comparisons and five
  rightward shifts. Placing the key is not counted as a shift. Equal keys retain
  identity and order. This is not a speed benchmark.
- Techniques: one visible intention per example and a readable resting frame.
  All four new technique sources passed native CLI checking (only unused static
  label hints) and formatting checks. Each was rendered as a six-frame storyboard
  with SwiftShader and visually inspected for the intended reading order,
  stagger timing, focus changes, attached-label relationship, overlap and clipping.
  Four actual 1280×720 resting-frame PNGs accompany the technique pages as static
  previews for browsers without WebGPU. These are stills, not evidence of browser
  animation playback or continuous-video review.

## Verification record

Record actual checks and rendering evidence in the final review report. A source
check, a static build, or a prerecorded playback is **not** evidence that live
WebGPU playback, parameter updates, seeking, or recovery work in a browser.
No audio synchronization is claimed by the silent typography work.
