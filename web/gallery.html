Embedding an Animatix Scene

The figures above originate from our curated interactive walkthroughs. Embedding any scene on the web requires just one script tag and custom element: 

<script type="module" src="./embed/amx-player.js" data-runtime-base="./pkg-slim"></script>

<amx-player src="./scenes/topology.amx" autoplay loop hold="1.5" aspect="16:9"></amx-player>
Vector and plain text scenes use the 5.5 MB pkg-slim bundle; load the full engine for Typst equations. web/README.md ↗
