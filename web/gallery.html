Embedding a scene

The seven figures above come from The Transformer Architecture, Animated, which explains them one at a time. Each scene source is a plain text file. 

<script type="module" src="./embed/amx-player.js"
        data-runtime-base="./pkg-slim"></script>

<amx-player src="./scenes/attention.amx" autoplay loop
            hold="1.5" aspect="16:9"></amx-player>

data-runtime-base on the loader script picks which engine profile to serve. These scenes use plain text only, so the page serves pkg-slim — the full profile is only needed for Typst markup, equations and image/SVG assets. web/README.md has the hosting notes.
