Embedding a scene

The figures above originate from The Transformer Architecture, Animated. Embedding any scene on the web requires just one script and tag: 

<script type="module" src="./embed/amx-player.js" data-runtime-base="./pkg-slim"></script>

<amx-player src="./scenes/attention.amx" autoplay loop hold="1.5" aspect="16:9"></amx-player>

data-runtime-base selects which engine wasm profile to download. Vector and plain text scenes use the 5.5 MB pkg-slim bundle. For full Typst equations and SVG assets, load the full engine profile. See web/README.md.
