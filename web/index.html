Animatix · WebGPU player

Play .amx scenes in the browser

Every animation on this page is a tiny declarative scene file rendered by the same engine as the desktop app. Embed one anywhere with a single <amx-player src="…"> element — no editor required, no backend, no build step. See the transformer walkthrough for a full article built from six embeds, and web/README.md for the hosting and embedding guide.

Edit scenes in the desktop app (cargo run -p animatix-gui); publish them as embeds here.
