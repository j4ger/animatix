01

One small language

An actor is one line. A keyframe is one line. Choreography reads the way you would describe it out loud — entrance, transform, move — with durations and eases attached inline. Scroll to scrub the stage, or click any line of code to jump to its beat:

scenes/sample.amx Click line to jump 
// one actor, three beats of choreography
box: Rect, size: (220, 220), color: accent.primary, at: (640, 360)
#0.5s
fade-in box [600ms, ease: ease-out]
#1.5s
box: Ellipse, size: (220, 170), color: accent.success [900ms, strategy: match]
#3.0s
shift box [by: (280, 0), 800ms, ease: ease-in-out]
scroll or click code lines to scrub playhead #0.0s

Underneath sits a real language: typed actors, reusable components, modules with imports, closures and reactive blocks, and GPU transitions. The interactive language tour walks all of it — with editable figures you can run live.

02

What's inside

Everything needed for technical storytelling, diagramming, and mathematical animation — designed from the ground up as a single coherent system.

01 / Primitives 32 Types

Shapes, Paths & Plots

From Rect and cubic Path to PlotCurve, NumberPlane, Heatmap, and Glass, all anchored to layout coordinates.

02 / Shaders 14 Passes

GPU Post-Processing

Blur, Bloom, MotionBlur, Vignette, and ColorGrade chains running natively on the GPU in real-time filter scopes.

03 / Stagecraft Light & Cam

Lighting & Camera

Radial and linear gradient washes, per-actor blend: "screen", animated dash patterns, value noise fields, and keyframable scene cameras.

04 / Typography Typst Core

Math & Code Typesetting

Equations, syntax-highlighted code, and rich typography typeset via an embedded Typst compiler; SVG and vector assets drop in as actors.

05 / Verbs 23 Actions

Choreography Built-ins

fade-in, draw-in, wipe-in, settle-in, shake, highlight, and shape morphing with automatic point matching.

06 / Reactive Compiled IR

Expressions & Loops

Closures, match, list comprehensions, and per-frame always blocks for orbital physics, generative motion, and live dials.

07 / Multi-Scene GPU Cuts

Scenes & Transitions

Multi-chapter explainers connected by GPU blends — directional wipes, cross-fades, and persistent actors that morph across cuts.

08 / Developer Tooling LSP + Studio

Desktop Studio & LSP

Real language tooling: desktop GUI previewer, live reload, LSP server with semantic diagnostics, formatter, and native plugin ABI.

09 / Web Runtime 5.5 MB Wasm

WebGPU in the Browser

The same Rust engine compiles to a WebGPU wasm module. A single <amx-player> HTML element embeds any scene with zero extra dependencies.

04

Try it in seconds

Run locally with Cargo, explore pre-built examples, or open the desktop studio:

Terminal 
# 1. Open the interactive desktop studio
cargo run -p animatix-gui

# 2. Render a single image frame
cargo run -p animatix-cli -- image examples/basics/00_hello.amx -o hello.png

# 3. Export a 60 FPS video (MP4/WebM)
cargo run -p animatix-cli --features video -- \
  video examples/gallery/epicycles.amx -o epicycles.mp4
