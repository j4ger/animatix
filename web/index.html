Animatix — a declarative animation language

01

One small language

An actor is one line. A keyframe is one line. Choreography reads the way you would describe it out loud — entrance, transform, move — with durations and eases attached inline. The source below is the figure beside it, beat for beat: scroll this section to scrub the stage, and watch the code line own the playhead. 

// one actor, three beats of choreography
box: Rect, size: (140, 140), color: accent.primary, at: (440, 360)
#0.5s
fade-in box [600ms, ease: ease-out]
#1.5s
box: Ellipse, size: (140, 110), color: accent.success [900ms, strategy: match]
#3.0s
shift box [by: (240, 0), 800ms, ease: bounce]

scroll to scrub · the lit line is the beat on stage #0.0s

Underneath sits a real language: typed actors, components with parameters and slots, modules with imports and namespaces, closures and always blocks for per-frame expressions, and a multi-scene format whose cuts are GPU transitions. The language tour walks all of it — and every figure there is editable, so you can change the code and watch the scene take it.

02

What's inside

31

Primitives

Shapes, text, plots, containers — from Rect and bezier Path to PlotCurve, NumberPlane and Heatmap, all with layout anchors.

13

GPU effects

Blur, MotionBlur, Vignette, ColorGrade… declared as labelled chains in a Filter scope — keyframeable, nestable.

19

Built-in actions

fade-in, draw-in, wipe-in, shake, highlight, swap — the verbs of explanation, plus morph re-declarations.

Typst

Text & math

Equations, syntax-highlighted code and styled text typeset through a Typst-powered text compiler; SVG and raster images drop in as actors.

IR

Expressions, reactive

Closures, match, lists, compile-time for — and always blocks that re-evaluate per frame for orbits, probing and generative motion.

N

Scenes & transitions

Multi-scene documents where the cuts are GPU blends — fade, four wipes, cut — with actors that persist across scenes.

LSP

Real tooling

Formatter, checker with named diagnostics, analyzer, LSP server, and a native plugin ABI. It is a language, not a config file.

wasm

In the browser

The same engine compiles to a WebGPU wasm module; one <amx-player> tag embeds a scene in any page — like every figure on this site.

  video examples/gallery/epicycles.amx -o epicycles.mp4

# or open the desktop studio
cargo run -p animatix-gui
