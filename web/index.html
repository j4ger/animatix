Inside

One coherent pipeline

Core runtime

Pure Rust & WebGPU

Hardware-accelerated 2D vector rasterization powered by Vello and custom WGSL compute shaders — native on desktop, a 2.3 MB slim runtime in the browser.

Typesetting

Math & code typography

Mathematical notation and syntax-highlighted code compiled directly via Typst into vector glyph actors.

Post-processing

GPU shader scopes

Real-time Gaussian blur, bloom, chromatic aberration, and frosted glass materials executing per frame.

Execution

Compiled reactive IR

Expressions, comprehensions, and orbital physics lowered into compact IR bytecode for zero-allocation evaluation at 60 FPS.

Workflow

From text to 4K video

# 1. Open the interactive desktop studio
cargo run -p animatix-gui

# 2. Render a single high-res vector frame
cargo run -p animatix-cli -- image examples/basics/00_hello.amx -o hello.png

# 3. Export a 60 FPS video (MP4 / WebM)
cargo run -p animatix-cli --features video -- \
  video examples/gallery/epicycles.amx -o epicycles.mp4
