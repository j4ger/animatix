Animatix · a declarative animation language

Explanatory animation,
written as text.

Animatix is a small language and a Rust rendering engine for explanatory animation — math, diagrams, vector motion. You describe scenes in a .amx file; a layout-first timeline and a GPU renderer do the rest, on the desktop and in the browser.

  • Rust · Vello / WebGPU
  • 31 primitives · 13 GPU effects · 19 actions
  • MIT licensed
01

One small language

An actor is one line. A keyframe is one line. Choreography reads the way you would describe it out loud — entrance, transform, move — with durations and eases attached inline. The whole sample below plays as a scene: 

// one actor, three lines of choreography
box: Rect, size: (120, 120), color: accent.primary, at: (640, 360)

#0.5s
fade-in box [600ms, ease: ease-out]

#1.5s
box: Ellipse, size: (120, 90), color: accent.success [900ms, strategy: match]

#3.0s
shift box [by: (200, 0), 800ms, ease: bounce]

Underneath sits a real language: typed actors, components with parameters and slots, modules with imports and namespaces, closures and always blocks for per-frame expressions, and a multi-scene format whose cuts are GPU transitions. The language tour walks all of it.

02

What's inside

31

Primitives

Shapes, text, plots, containers — from Rect and bezier Path to PlotCurve, NumberPlane and Heatmap, all with layout anchors.

13

GPU effects

Blur, MotionBlur, Vignette, ColorGrade… declared as labelled chains in a Filter scope — keyframeable, nestable.

19

Built-in actions

fade-in, draw-in, wipe-in, shake, highlight, swap — the verbs of explanation, plus morph re-declarations.

Typst

Text & math

Equations, syntax-highlighted code and styled text typeset through a Typst-powered text compiler; SVG and raster images drop in as actors.

IR

Expressions, reactive

Closures, match, lists, compile-time for — and always blocks that re-evaluate per frame for orbits, probing and generative motion.

N

Scenes & transitions

Multi-scene documents where the cuts are GPU blends — fade, four wipes, cut — with actors that persist across scenes.

LSP

Real tooling

Formatter, checker with named diagnostics, analyzer, LSP server, and a native plugin ABI. It is a language, not a config file.

wasm

In the browser

The same engine compiles to a WebGPU wasm module; one <amx-player> tag embeds a scene in any page — like every figure on this site.

04

Try it

# render a frame / a film
cargo run -p animatix-cli -- image examples/basics/00_hello.amx -o hello.png
cargo run -p animatix-cli --features video -- video examples/gallery/epicycles.amx

# or open the desktop studio
cargo run -p animatix-gui

Read the language: docs/spec.md — the full specification, docs/primitives.md — the actor catalog.

Learn by example: 62 runnable .amx files, from a hello card to a Fourier-epicycles story.

Embed on the web: web/README.md — the <amx-player> attribute reference and hosting notes.
