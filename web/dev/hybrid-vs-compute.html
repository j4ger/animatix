vello_hybrid (WebGL2) vs vello compute (WebGPU) — per-frame cost

Same synthetic vector scene, two renderers, one wasm module. Times are per frame. submit = CPU build+encode+submit; gpu = the rest after a GPU sync; clear = empty-scene fixed overhead. Compute renders offscreen then blits (production path); hybrid renders straight to the WebGL2 canvas. Sync differs by backend (onSubmittedWorkDone vs readPixels) — both wait for the GPU. Not representative of effects/transitions/text shaping, which this probe excludes.
