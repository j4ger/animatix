The Transformer Architecture, Animated

Six short animations that build the transformer up piece by piece — tokens, positional encoding, attention, multi-head attention, the feed-forward block, and the full stack. Each one is a declarative scene file embedded below with a single <amx-player src="…"> element. View source to see how little it takes.

1From text to tokens

A transformer never sees words. Text is split into tokens, and each token is replaced by a learned vector — an embedding — that encodes what it means. Everything downstream operates on these vectors.

2Positional encoding

Attention has no built-in sense of order, so each position is stamped with a fingerprint built from sine waves of growing wavelength. The same word at a different position gets a different vector.

3Self-attention

The core idea. Every token asks a question (the query), advertises what it contains (the key), and offers its content (the value). Softmax over the query–key scores decides how much each token pulls from every other token.

4Multi-head attention

One attention pattern is rarely enough, so the model runs several in parallel. Each head is free to specialize — grammar, references, neighborhoods — and their outputs are concatenated and mixed.

5Feed-forward & residuals

Attention moves information between tokens; the feed-forward network then transforms each token on its own, widening 4× and projecting back. Skip connections keep the original signal one hop away, so depth adds refinement instead of forgetting.

6Stacking the blocks

One attention-plus-FFN block is a layer. Stack N of them, share the weights within each layer, and tokens flow up the tower — arriving at the top contextualized and ready for a language-modeling or task head.
