Chapter 00 · Autoregressive Feedback

The Blueprint: A Machine That Writes One Word at a Time

Large language models can write essays, debug complex code, and simulate logical debate. Yet beneath this apparent general intelligence lies an astonishingly focused operational truth: the model is an iterative, next-token prediction engine.

When you submit a prompt, the model does not plan or generate an entire response in one stroke. Instead, the input sequence enters along the bottom baseline. Signals ascend through N stacked blocks. Self-attention routes context horizontally between words, while feed-forward networks recall factual memory. At the summit, the Language Model (LM) Head projects hidden states into a probability distribution over the vocabulary. The single winning candidate appends back onto the input row — and the entire forward pass repeats. That closed feedback loop is autoregressive generation.

yt = argmax P(tokent ∣ tokens1:t−1)

The Generative Snowball & Causal Autoregression: Unlike masked models (such as BERT) that require explicit [MASK] placeholder tokens, an autoregressive decoder (like GPT, Claude, or DeepSeek) requires no placeholder. The model takes the prompt tokens as-is, reads the hidden vector of the very last token at layer N, and projects it into vocabulary logits. The single winning candidate is appended to extend the sequence, advancing the generative frontier one step at a time. To prevent quadratic recomputation, modern inference engines maintain a KV-Cache to store past key and value vectors.
Chapter 01 · Vector Extrusion

From Discrete Text to High-Dimensional Coordinates

Computers store human text as discrete byte sequences (such as ASCII or UTF-8). To a deep neural network, however, raw characters are mathematically opaque: a neural weight matrix cannot multiply against character glyphs like 'animal'.

Historically, NLP used one-hot vectors, assigning every word an isolated basis vector. But one-hot vectors are disastrous: a 50,000-word vocabulary produces 50,000-dimensional sparse vectors where every word is strictly orthogonal to every other word. In one-hot space, cat is as distant from kitten as it is from refrigerator.

Modern models solve this in two steps:

1. Byte-Pair Encoding (BPE): Text fractures into statistically optimal sub-word tokens, striking a perfect balance between character flexibility and word-level efficiency. Each sub-word maps to an integer ID in a 50,257-token codebook.

2. Continuous Coordinate Extrusion: A learned embedding matrix W_e extrudes each integer ID into a 768-dimensional coordinate row (in GPT-2 Small, $d_{model} = 768$). In this high-dimensional continuous geometry, spatial proximity directly reflects conceptual meaning, and semantic relationships become geometric vector arithmetic: v(king) - v(man) + v(woman) ≈ v(queen).

xi = We [ token_idi ] ∈ ℝdmodel   (dmodel = 768)

Chapter 02 · Temporal Fingerprints

Injecting the Arrow of Time: Harmonic Positional Encodings

Once words become continuous vectors, they enter the Transformer. Here lies a fundamental paradox: Self-Attention is strictly permutation-invariant. If you scramble the words of a sentence into a random order, an attention matrix computes the exact same values. To an order-blind attention layer, "dog bites man" and "man bites dog" appear identical.

Why not simply append an integer step counter (1, 2, 3...) to each word? Naive integer counters fail in deep backpropagation: as sequence lengths grow at inference time, unbounded index values blow up network activations and introduce scale mismatch.

The Transformer's solution is elegant: Harmonic Sinusoidal Frequencies. For each dimension index $2i$, the model computes a sine wave; for $2i+1$, a cosine wave. Wavelengths double progressively across rows from fine to coarse resolution ($\lambda = 3, 6, 12, 24$). Low dimensions oscillate rapidly, capturing fine relative offsets; high dimensions oscillate slowly, providing a smooth global position coordinate.

This harmonic spectrum adds element-wise directly onto the token embedding (x_i = e_i + p_i). Because trigonometric functions satisfy linear rotation identities, the model can learn to attend by relative distance simply by taking linear combinations.

PE(pos, 2i) = sin(pos / 100002i/d),    PE(pos, 2i+1) = cos(pos / 100002i/d)

The Blessing of Dimensionality: Why Addition Doesn't Destroy Meaning: In 2D or 3D geometry, adding two vectors drastically alters their direction. But in $d_{model} = 768$ dimensions, space behaves counter-intuitively: almost all random vectors are mutually orthogonal ($x^T y \approx 0$). High-dimensional space possesses vast geometric capacity, allowing token semantics, position frequencies, and later sublayer updates to travel in distinct, near-orthogonal subspaces like separate lanes on an 8-lane highway without colliding.
Chapter 03 · Contextual Routing

How Words Communicate: Scaled Dot-Product Self-Attention

Before Transformers, Recurrent Neural Networks (RNNs) passed information sequentially from word to word like a game of telephone. In long sentences, early context was inevitably washed away. Self-Attention shattered this bottleneck by establishing direct, pairwise $O(1)$ communication between every pair of words in the sentence.

To coordinate communication, each token vector projects into three distinct roles via learned weight matrices (W_Q, W_K, W_V):

• Query (Q): What this token seeks from others.
• Key (K): What this token advertises to matching queries.
• Value (V): The substantive semantic payload this token delivers.

Why not compute dot products directly between original vectors (x_i^T x_j)?
Because original dot products are strictly symmetric: $x_i^T x_j = x_j^T x_i$. In natural language, however, syntactic and semantic dependencies are directional and asymmetric: a pronoun eagerly searches for its antecedent noun, but the noun does not reciprocate that need. Linear projections $W_Q$ and $W_K$ break the symmetry ($Q K^T \neq K Q^T$). Meanwhile, an independent $W_V$ decouples the indexing criteria (what matches) from the semantic payload (what is retrieved).

Consider the famous Winograd Schema challenge: "The animal didn't cross the street because it was too tired". To interpret "it", the model must decide whether it refers to "animal" or "street". The token "it" emits a Query searching for an antecedent with fatigue attributes. Taking dot products against all preceding Keys measures geometric alignment: the affinity with "animal" scores 0.64, decisively outcompeting "street" at 0.18.

Scores are scaled by 1 / √d_k to maintain unit variance in high dimensions (preventing Softmax from saturating into vanishing gradients). Finally, Softmax weights guide a weighted sum over all Value vectors: the pronoun "it" absorbs the rich entity features of "animal".

Attention(Q, K, V) = softmax((QKT / √dk + M)) V

The Causal Masking Law: In bidirectional models (such as BERT encoders), tokens can look both left and right. But in generative decoders (GPT, Llama, DeepSeek), the model must never peek into the future. A causal mask matrix $M$ enforces this by setting upper-triangular affinities ($j > i$) to $-\infty$. Because $e^{-\infty} = 0$, future attention weights become zero. Notice that in our example, "it" is the 6th token looking backward at "animal" (token 2) and "street" (token 4) — strictly honoring the causal boundary!
For Computer Vision Veterans: Dynamic Convolutions with Infinite Receptive Field: In a standard CNN (ResNet, VGG), a $3 \times 3$ convolutional kernel has fixed, frozen weights and a narrow, local receptive field that expands slowly over depth. Self-Attention fundamentally reimagines this: 1. Global Receptive Field ($O(1)$) from Layer 1: Every token can directly query any other token in a single step, bypassing the multi-layer receptive field dilation required in CNNs. 2. Data-Dependent Dynamic Weights: Rather than applying static parameters, the attention filter $A = \text{softmax}(QK^T / \sqrt{d_k} + M)$ is computed at runtime from the inputs themselves. Self-Attention is mathematically an input-adaptive, dynamic depthwise convolution with infinite receptive field!
Chapter 04 · Parallel Subspaces

Multiple Lenses at Once: Multi-Head Parallel Attention

Language is inherently multidimensional. At any instant, a single word participates in multiple simultaneous relationships: grammatical agreement, pronoun coreference, modifier binding, and syntactic predicate structure. A single attention head can only produce one probability distribution per word — forcing the model to compromise and average diverse relationships into a blurred composite.

Multi-Head Attention resolves this by projecting the 768-dimensional model state into 12 parallel 64-dimensional subspaces ($12 \times 64 = 768$). Each head operates as an independent, specialized lens:

• Head 1 (Coreference): Resolves pronouns across clauses ("it" → "animal", weight 0.88).
• Head 2 (Syntax): Resolves verb negation to preceding auxiliary ("cross" → "didn't", weight 0.92).
• Head 3 (Modifier Binding): Binds spatial object to preceding action ("street" → "cross", weight 0.85).

Each head computes attention independently within its 64-dimensional subspace. The 12 resulting vectors are concatenated into a $12 \times 64 = 768$ matrix, and a final linear projection matrix W_O synthesizes the multi-aspect insights back into the main residual stream.

MultiHead(Q, K, V) = Concat(head1, …, headh) WO

The Dimension Trap: Why We Must Multiply by W_O: Concatenating 12 heads of 64 dimensions each yields $12 \times 64 = 768$ dimensions — exactly matching $d_{model}$! Why not add it directly to the residual stream? Without $W_O$, the heads remain isolated silos: Head 1's features are forever locked in dimensions 0–63, Head 2 in 64–127, unable to interact. Matrix $W_O \in \mathbb{R}^{768 \times 768}$ acts as an Inter-Head Mixing Console, linearly cross-blending syntax clues, entity bindings, and modifiers across the full coordinate space so downstream blocks can reason over them jointly.
Chapter 05 · Associative Memory & Residuals

The Memory Highway: Storing Facts in Higher Dimensions

There is a fundamental division of labor inside every Transformer block: Self-Attention routes information between tokens; the Feed-Forward Network (FFN) processes each token alone.

Pioneering interpretability research (Geva et al., 2021) demonstrated that the FFN functions as a vast key-value factual memory. In the first linear layer, coordinates expand 4× from 768 to 3072 dimensions. In this expansive high-dimensional space, GELU nonlinearities act as concept detectors: specific neurons fire when certain factual associations appear (e.g., retrieving the common-sense fact that animals cannot walk when exhausted). The second linear layer contracts the representation back to 768 dimensions.

Connecting every sublayer is the Residual Stream Highway. Rather than forcing representations through destructive transforms, the identity signal travels straight along an unbroken bus. Both Attention and FFN compute only additive deltas (Δx) injected back into the stream: x_{l+1} = x_l + \text{Sublayer}(\text{LayerNorm}(x_l)). This residual highway allows gradients to propagate unimpeded across dozens of layers during training, eliminating the vanishing gradient problem.

FFN(x) = ∑m=13072 GELU(xT km + b1,m) vm + b2

The Mathematical Bridge: Why FFN Is a Key-Value Memory: By decomposing $W_1$ into 3072 column vectors $k_m$ and $W_2$ into 3072 row vectors $v_m$, the matrix multiplication expands into $\text{FFN}(x) = \sum c_m v_m$. Each $k_m$ serves as a Key (Concept Detector): calculating inner product affinity against the current token. When a pattern matches (e.g., 'animal entity' + 'fatigue context'), GELU fires. The corresponding $v_m$ serves as the Value (Knowledge Patch): delivering factual updates (e.g., 'requires rest / halted motion') injected as an additive delta into the residual highway.
For Computer Vision Veterans: The 1×1 Pointwise Convolution Equivalence: To a vision engineer, the FFN is mathematically identical to a pair of $1 \times 1$ Pointwise Convolutions with an inverted bottleneck:
\text{FFN}(x) = \text{Conv1D}_{1\times 1}(\text{GELU}(\text{Conv1D}_{1\times 1}(x)))
It expands channels 4× from 768 to 3072, applies non-linearity, and projects back, operating across the sequence dimension without mixing tokens (exactly like 1×1 convolutions operate across spatial pixels without mixing coordinates). Modern vision networks like ConvNeXt and MobileNetV2 adopted this inverted bottleneck directly from the Transformer!
Chapter 06 · Deep Assembly Line

The Deep Assembly Line: From Surface Syntax to Logit Projection

A single Transformer block performs one round of contextual routing and memory retrieval. The true power of modern language models emerges when blocks are stacked into a deep assembly line ($N = 12$ layers in GPT-2 Small, $N = 32$ in Llama 3 8B, $N = 80+$ in frontier models).

As token representations ascend through the 12-layer stack, meaning undergoes a profound qualitative evolution:

• Layers 1–4 (Surface Syntax): Attention heads attend locally, grouping tokens into n-grams, identifying parts of speech, and mapping shallow grammar.
• Layers 5–8 (Relational Semantics): Long-range heads activate, building entity representations, resolving cross-clause coreferences, and tracking subject-predicate relations.
• Layers 9–12 (Abstract Intent): Deep blocks synthesize context, performing pragmatic inference and anticipating the next logical thought.

At the top of the stack, the hidden vector of the final token passes into the Language Model Head. A linear un-embedding matrix projects the 768-dimensional vector into 50,257 logits — one raw affinity score for every token in the vocabulary. Normalized through Softmax, logits become a probability distribution. In our sentence, "street" emerges victorious with 41% probability, followed by "road" (22%) and "bridge" (12%). The winning token is appended to the input, and the autoregressive cycle begins anew.

P(tokent+1 ∣ tokens1:t) = softmax(WU hL(t)) ∈ ℝ50,257

Chapter 07 · Cross-Domain Bridges

The Rosetta Stone: Transformers for the CNN Mind

For practitioners trained in computer vision and classical machine learning, shifting from Convolutional Neural Networks (CNNs) to Transformers can initially feel disorienting. The tensor layouts differ, the inductive biases change, and familiar concepts like sliding windows and receptive fields seem absent.

In reality, the two paradigms share deep mathematical parallels. Below is a structural mapping translating every core Transformer mechanism into its familiar CNN equivalent:

Core Dimension Classical CNN (ResNet / ConvNeXt) Transformer (LLM / ViT) Cross-Domain Intuition
Data Tensor 4D Tensor: [B, C, H, W] 3D Tensor: [B, L, D] L = H × W (flattened spatial patches); D = C (feature channels)
Spatial Context Static local kernel K × K (frozen weights) Self-Attention (dynamic runtime weights) Input-adaptive dynamic convolution with global O(1) receptive field
Channel Transformation 1×1 Pointwise Conv / Inverted Bottleneck Feed-Forward Network (FFN: 768 → 3072 → 768) Mathematically identical token-wise channel expansion and non-linear mapping
Subspace Branching Grouped Convolution (ResNeXt cardinality) Multi-Head Attention (12 heads × 64 dim) Parallel orthogonal feature subspaces recombined via 1×1 projection (W_O)
Position & Geometry Hard-coded grid translation equivariance Permutation-invariant + Harmonic Encodings Weak inductive bias with high capacity replacing hard spatial constraints
Residual Philosophy y = x + F(x) (branch computes feature; skip avoids loss) x_(l+1) = x_l + Δx (highway is central bus; sublayers write deltas) Shift from "shortcut bypass" to "central shared communication bus"
Normalization Batch Normalization (cross-spatial, per-channel) Layer Normalization (per-token, cross-channel) Independent of sequence length and batch size; zero cross-time leakage
The Victory of Weak Inductive Biases: Why did Vision Transformers (ViT) eventually overtake traditional CNNs on massive benchmarks? CNNs enforce a "hard" spatial inductive bias (nearby pixels must be related). While this prevents overfitting on small datasets, it caps model capacity on massive corpora. By treating images as a bag of flattened patches with no built-in spatial bias, the Transformer gives the model freedom to discover arbitrary long-range correlations on its own.
