The Transformer Architecture, Animated

Every frontier language model — GPT-4, Claude, Llama 3 — is powered by one core machine repeated in a stack: the transformer block. This walkthrough dissects the architecture piece by piece. Every figure below is not a pre-rendered video, but a declarative .amx scene compiled inside your browser and rendered at 60 FPS via WebGPU.

⚡ The Core Mental Model: Tokens Flow Up

Text enters at the bottom as discrete symbols, converts into high-dimensional coordinate vectors, and climbs through an assembly line of identical blocks. Inside each block, self-attention mixes information between tokens, and the feed-forward network transforms each token on its own. At the summit, the refined vector projects onto the vocabulary to predict the single most probable next word.

01

From Text to High-Dimensional Coordinates

💡

Key Intuition: Neural networks cannot read letters or words. Every piece of text must be fractured into statistical fragments and mapped into a 768-number coordinate vector in an abstract continuous space.

The first operation applied to raw text is tokenization. Using algorithms like Byte-Pair Encoding (BPE), a trained tokenizer breaks strings into sub-word tokens — whole short words, syllables of longer words, punctuation, and spaces. Common words like the stay whole; complex words split into pieces (un · believ · able). Modern byte-level tokenizers can encode any string in any language without encountering an “unknown word”.

Each unique token ID acts as an index into a massive learned lookup table: the embedding matrix. If the vocabulary has 50,257 entries and the model width is d_model = 768, the table holds 50,257 separate 768-dimensional vectors. Looking up token 4,132 returns row 4,132: 768 floating-point numbers that encapsulate the semantic essence of that token. From this point on, raw letters disappear completely; the model operates purely on geometry and linear algebra.

How the figure unfolds

  1. 1The raw input string — the unbroken character sequence received by the model.
  2. 2Sub-word fracture — the tokenizer splits the text into statistically optimal BPE chips.
  3. 3Embedding lookup — each chip retrieves its learned d_model vector from the embedding table.
01 DATA By the Numbers (GPT-2 Small)
  • Vocabulary size: 50,257 distinct sub-words
  • Embedding width (d_model): 768 float32 numbers
  • Embedding table size: 38.6 million dedicated parameters
TECH DEEP DIVE Why LLMs Struggle to Count Letters

Because BPE compresses character clusters into atomic token IDs before the model ever receives them, individual characters do not exist as independent entities in the neural representations. The model only observes the holistic token vector.

02

Positional Encoding: Injecting the Arrow of Time

💡

Key Intuition: Self-attention is inherently permutation-invariant. Without positional encoding, “dog bites man” and “man bites dog” produce identical mathematical outputs. Word order must be injected manually into every token.

Because attention operations calculate pairwise similarities across all tokens simultaneously, they treat input sequences as an unordered set. Shuffling the inputs simply shuffles the outputs. To give the model a sense of order, we compute a distinct positional fingerprint vector for each sequence index t (from 0 to N−1) and add it directly to the token embedding: x_0 = embedding + position.

The original 2017 transformer constructs these fingerprints using interleaved sine and cosine waves of geometrically growing wavelengths. Dimension 0 oscillates at a high frequency (period 3 in the schematic below), while higher dimensions oscillate progressively slower (period 6, 12, 24, up to thousands of tokens). Reading across, every position acquires a unique cryptographic code. Reading down, smooth harmonic transitions allow the network to learn relative offsets: the relationship between position t and t+k is a linear rotation that looks consistent anywhere in the context.

How the figure unfolds

  1. 1The coordinate matrix sweeps in — 8 positions across 4 sample dimensions.
  2. 2Geometric period doubling — rows display periods 3, 6, 12, 24, progressing from rapid oscillations to smooth gradients.
  3. 3Fingerprint extraction — the cursor isolates column 3, showing the exact additive vector injected into token 3.
02 DATA Positional Wave Specs
  • Wavelength spectrum: 2π → 10,000 · 2π across dimensions
  • GPT-2 alternative: Learned absolute position vectors
  • Modern standard (Llama 3, Mistral): Rotary Embeddings (RoPE)
TECH DEEP DIVE The Rise of Rotary Position Embeddings (RoPE)

Instead of adding static vectors at the base of the network, modern models use RoPE: they rotate query and key vectors inside attention by an angle proportional to position. This ensures dot products depend solely on relative distances (tq − tk) and enables extrapolation to 128k+ token contexts.

03

Self-Attention: The Dynamic Spotlight

💡

Key Intuition: Self-attention allows tokens to exchange context. Every token acts as a Query (what it seeks), a Key (what it advertises), and a Value (what it gives). Softmax normalizes compatibilities into a probability distribution that sums to exactly 1.0.

Attention is the core operational powerhouse of the transformer. For every token, its incoming vector is multiplied by three learned projection matrices to produce three vectors:

  • Query (Q): The question being asked (e.g., “I am the pronoun ‘it’; which antecedent noun do I refer to?”).
  • Key (K): The tag or topic advertised (e.g., “I am the noun ‘animal’, singular, subject”).
  • Value (V): The actual content transmitted if the query matches the key.

The compatibility score between query q and key k is their dot product: q · k. We scale this score by dividing by √d_k (where dk = 64, dividing by 8) to prevent scores from growing excessively large and driving softmax gradients into saturation. Passing scores through a softmax turns them into positive weights summing to 1.0. Finally, the token's updated representation is the weighted sum: Σ w · V.

How the figure unfolds

  1. 1Query activation — the pronoun it initiates a backward search across preceding tokens.
  2. 2Score computation — dot products are calculated between the query and all preceding keys.
  3. 3Softmax sharpening — scores pass through softmax; animal captures 62% of the total attention budget.
03 FORMULA Scaled Dot-Product Attention

Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V

  • Head dimension: d_k = 64 (divisor = 8)
  • Normalization: weights strictly sum to 1.0
  • Decoder property: causal mask hides future tokens
TECH DEEP DIVE Attention Budget Dilation

Because softmax enforces a fixed probability budget (weights sum to 1.0), extending the context window to 32k or 128k tokens naturally dilutes individual weights. If an important fact is surrounded by thousands of irrelevant tokens, its attention share can be diluted into noise.

04

Multi-Head Attention: Parallel Subspaces of Thought

💡

Key Intuition: Language requires tracking multiple relationships simultaneously (grammar, semantics, coreference, rhythm). Instead of running one wide attention calculation, the model splits into h parallel heads operating in distinct subspaces.

A single attention mechanism can only focus on one pattern per token at a time. To track grammatical agreement (subject ↔ verb), semantic binding (verb → direct object), and sequential proximity all at once, the transformer runs h heads in parallel.

The computational budget remains constant: h heads × dk dims = dmodel. In GPT-2 Small, 12 heads of 64 dimensions each equal the 768-dimensional model width. Each head projects Q, K, V into its own private 64-dimensional subspace, calculates independent attention patterns, and produces an output vector. Finally, the outputs from all h heads are concatenated back to full width and passed through a learned output projection matrix (WO) to fuse their findings into a unified representation.

How the figure unfolds

  1. 1Subspace division — three parallel panels initialize for the same input sequence.
  2. 2Specialized attention maps — each head populates its distinct 3×3 attention matrix.
  3. 3Concatenation and fusion — head outputs align into a single continuous bar and project through WO.
04 DATA Head Allocations
  • GPT-2 Small: 12 heads × 64 dims = 768
  • GPT-3 (175B): 96 heads × 128 dims = 12,288
  • Llama 3 (70B): 64 query heads / 8 KV heads (GQA)
TECH DEEP DIVE Induction Heads & In-Context Learning

Mechanistic interpretability research revealed that in-context learning is driven by induction heads: circuits of two attention heads where Head A looks back for previous occurrences of a pattern, and Head B copies what token followed. This circuit enables few-shot pattern matching.

05

Feed-Forward Memory & The Residual Highway

💡

Key Intuition: Self-attention mixes tokens together; the Feed-Forward Network (FFN) transforms each token alone. It inflates into a 4 × dmodel memory chamber where learned factual knowledge is stored and retrieved.

After attention aggregates context from other tokens, the representation enters the Feed-Forward Network (FFN). Unlike attention, the FFN operates on each position completely independently, applying an identical two-layer MLP: widen from dmodel to 4 · dmodel, pass through a non-linear activation (GELU or SwiGLU), and project back down to dmodel.

Why widen the vector fourfold? In that expanded intermediate space, the network maintains an associative key-value memory. First-layer neurons act as pattern detectors for concepts and facts; second-layer weights write the associated factual updates back into the token's vector. The FFN accounts for two thirds of all parameters in every block.

Crucially, both attention and the FFN wrap around a central conduit: the residual stream. Sublayers do not overwrite the flowing vector; they add to it: x ← x + Sublayer(LayerNorm(x)). The residual stream acts as an uninterrupted computational highway running through all 100+ layers, ensuring gradients flow back to the input without vanishing.

How the figure unfolds

  1. 1The residual rail establishes the highway — the unbroken carrier line for token representations.
  2. 2Sublayer execution — LayerNorm stabilizes magnitudes; attention mixes context; FFN expands 4× to process facts.
  3. 3Additive skip junctions — outputs add back via skip connections (+) without replacing original signals.
05 DATA Parameter Distribution
  • Attention sublayer: 4 · d² parameters (Q, K, V, O matrices)
  • Feed-forward sublayer: 8 · d² parameters (widen + narrow)
  • FFN proportion: ~66.7% of all parameters in each block
TECH DEEP DIVE Knowledge Neurons & Modern SwiGLU / MoE

Modern models enhance the FFN in two ways: SwiGLU gates the expansion with a third matrix for smoother non-linearity, and Mixture-of-Experts (MoE) splits the FFN into 8 or 64 specialized experts, dynamically activating only 2 per token to triple parameter capacity without increasing compute cost.

06

Stacking the Blocks: The Tower of Abstraction

💡

Key Intuition: A complete language model stacks N identical blocks in series. As the token vector ascends the tower, its meaning deepens: from surface spelling to grammar, from factual reasoning to vocabulary logits.

One attention-plus-FFN assembly constitutes one layer. The full model stacks N of these layers sequentially — 12 in GPT-2 Small, 32 in Llama 3 8B, and 96 in GPT-3. While all blocks share the exact same internal wiring, each block owns its own independent weights.

Empirical probing demonstrates a clear gradient of abstraction up the tower:

  • Early layers (1–4): Model local surface patterns, token bigrams, and syntax.
  • Middle layers (5–20): Resolve coreference, entity attributes, and world knowledge.
  • Top layers (21–N): Synthesize context into task-specific features and next-token predictions.

At the summit of the stack sits the Language Model (LM) Head: a final linear projection that maps the dmodel-dimensional vector to the full vocabulary size (50,257 logits), followed by a softmax. Sampling from this distribution yields the generated token, which is appended to the prompt to start the next cycle.

How the figure unfolds

  1. 1Prompt ingestion — embedded tokens enter the bottom of the transformer stack.
  2. 2Sequential block refinement — the vector climbs from Block 1 through Block N, acquiring richer context.
  3. 3Head projection — the final vector projects to the LM Head for next-token generation.
06 DATA Layer Scaling
  • GPT-2 Small: 12 layers · GPT-2 XL: 48 layers
  • Llama 3 70B: 80 layers · GPT-3: 96 layers
  • LM Head output: 50,257 to 128,256 logits per step
TECH DEEP DIVE The KV Cache Optimization

During autoregressive generation, recomputing attention for past tokens on every step would require O(N³) compute. Modern inference engines use a KV Cache: past key and value vectors are stored in GPU memory, so generating each new token only requires computing Q, K, V for the single newest token (O(N) per step).

07

Synthesis, Architectural Evolution & Glossary

That is the complete machine. In summary, a single forward pass through a modern transformer executes the following immutable sequence:

  1. Tokenize — Text fractures into sub-word vocabulary IDs via BPE.
  2. Embed & Stamp — IDs retrieve dmodel vectors; positional encodings inject sequence order.
  3. Repeat N Layers — For each block:
    • Multi-Head Attention mixes context across tokens: x ← x + MHA(LN(x)).
    • Feed-Forward MLP updates factual representations: x ← x + FFN(LN(x)).
  4. LM Head — Final vectors project onto vocabulary logits (dmodel → |V|).
  5. Softmax & Sample — Sample the next token, append it to the context, and repeat.
