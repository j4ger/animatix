Architecture Blueprint · Autoregressive Feedback

The Transformer Block at a Glance

Frontier language models do not generate whole sentences at once; they run a continuous, iterative snowball. In each forward pass, input tokens ascend through N stacked blocks. Self-attention routes context horizontally between words, while feed-forward networks recall factual memory. At the summit, the LM Head projects hidden states into vocabulary probabilities. The winning token appends back onto the input sequence — that feedback loop is autoregressive generation.

01 · Vector Extrusion

From Text to High-Dimensional Coordinates

Neural networks compute on continuous geometry, not raw characters. Byte-Pair Encoding (BPE) fractures the string into statistically optimal sub-word tokens, mapped to integer IDs in a 50,257-token codebook. An embedding matrix W_e then extrudes each ID into a 768-dimensional coordinate row, translating discrete symbols into a rich semantic vector space where spatial proximity reflects conceptual meaning.

02 · Temporal Fingerprints

Injecting the Arrow of Time

Self-attention calculates pairwise affinities without regard to order: it treats tokens as an unordered bag of words. To distinguish sequence order, Transformers add a deterministic harmonic sinusoidal spectrum (x_i = e_i + p_i). Wavelengths double across dimensions, giving each sequence index a distinct, continuous mathematical fingerprint.

04 · Parallel Subspaces

Tracking Multiple Relationships in Parallel

A single attention head averages competing relationships into a blurred composite. By projecting hidden states into 12 parallel 64-dimensional subspaces, Multi-Head Attention allows distinct heads to specialize concurrently: Head 1 resolves pronoun coreference ("it" → "animal"), Head 2 enforces syntactic verb negation ("didn't" → "cross"), while Head 3 tracks local modifier dependencies ("cross" → "street"). Their outputs concatenate and project back into d_model via W_O.

1
Subspace Projection The 768-dim state projects into 12 specialized 64-dim subspaces (12 × 64 = 768).

Parallel Specialization Independent heads simultaneously track syntax, coreference, and grammatical modifiers.
3
Linear Synthesis All 12 head vectors concatenate and project via W_O back into the residual highway.

05 · Associative Memory

Nonlinear Memory Recall in Higher Dimensions

While attention routes information between tokens, the Feed-Forward Network (FFN) operates on each token alone. Expanding coordinates 4× to 3072 dimensions creates a high-capacity sparse associative memory space for factual recall via GELU nonlinearities, before projecting back as an additive delta (Δx) onto the central residual highway.

Dimensional Expansion: 768 → 3072 → 768 Activation: GELU Nonlinearity Residual Highway: x + FFN(LN(x))
1
Residual Highway The unbroken central bus carries token identity across all layers without signal degradation.
2
4× Dimensional Widen Expands to 3072 features to activate sparse associative memory keys.
3
Additive Delta Fusion Projected delta adds directly back into the highway: x_(l+1) = x_l + FFN(LN(x_l)).
