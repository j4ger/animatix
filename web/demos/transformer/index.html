1Words become vectors

A neural network cannot multiply a word like animal. The tokenizer first splits text into sub-word chunks and looks each up in a learned table, which returns a vector of dmodel numbers — its coordinates in meaning space. In that space, direction carries meaning: v(king) − v(man) + v(woman) ≈ v(queen).

Everything that follows — attention, memory, logits — operates on these vectors and on nothing else. The embedding table is the only part of the model that actually knows how to spell.

2Order is added back in

Attention is order-blind: shuffle the words and it computes the same result, so "dog bites man" and "man bites dog" look identical. The fix is to add a position vector to every token, built from sine and cosine waves of doubling wavelength — fine fast-oscillating dimensions encode nearby positions, slow ones encode coarse ones.

In 768 dimensions these additions barely disturb each other — token meaning and position ride in nearly orthogonal subspaces, which is why a plain sum is enough.

3Attention routes context

This is the core mechanism. Every vector projects into three roles through learned matrices: a Query (what it is looking for), a Key (what it advertises), and a Value (what it hands over if matched). Dot products between one query and all keys score the matches; softmax turns the scores into weights; the weights mix the values.

Attention(Q, K, V) = softmax(QKT / √dk + M) V

Generative models also apply a causal mask: scores against future positions are set to −∞, so a token can only look left. That single constraint is what makes next-word training possible.

4Twelve lenses at once

One attention pass produces one pattern of weights — but a word participates in several relationships at once. So the 768-dim state is split into twelve 64-dim subspaces, each running its own attention with its own specialties: one tracks coreference, one syntax, one modifier binding. The twelve outputs are concatenated and re-mixed by a final matrix WO so the lanes can talk to each other.

5The FFN recalls facts

Attention moves information between tokens; the feed-forward network works on each token alone. It expands the vector 4× to 3072 dimensions, applies a non-linearity, and projects back. Interpretability research reads the first layer as a bank of concept detectors and the second as the facts they release — a key-value memory consulted token by token.

Note what the figure shows along the bottom: the sublayers do not transform the stream, they add to it (x + Attn(x), then x + FFN(x)). This residual highway is what lets gradients flow through dozens of layers.

6Stacked, then predicted

Stack the block N times — 12 in GPT-2, 32 in Llama-3-8B — and meaning sharpens as it climbs: early layers handle grammar, middle layers entities and relations, late layers intent. The final vector feeds the LM head, which scores every token in the vocabulary; softmax turns the scores into a probability for the next word.

That loop — predict one word, append it, predict again — is the whole trick. Everything else in this article was engineering to make this one step good.
