01

From Text to High-Dimensional Coordinates

THE MECHANISM

Neural networks operate on geometry, not strings. Every piece of text fractures into sub-word tokens and retrieves a 768-dimensional coordinate vector from a learned lookup table.

Fig 01 // Sub-Word Fracture & Extrusion
pkg-slim · 1.6MB 60 FPS WEBGPU
Vector Extrusion · Sub-Word Representation

The continuous sentence fractures into discrete token chips. Each chip looks up its row in the embedding matrix, extruding a column of numerical coordinates.

tokens.amx ↗

Choreography beats

  1. 1The raw input string — the unbroken character sequence received by the model.
  2. 2Sub-word fracture — the tokenizer splits the text into statistically optimal BPE chips.
  3. 3Embedding lookup — each chip retrieves its learned d_model vector from the embedding table.
Vocabulary Specs & Tokenization Details

Using Byte-Pair Encoding (BPE), the tokenizer splits strings into common sub-words (un · believ · able). Each unique token ID acts as an index into the embedding matrix: if vocabulary size is 50,257 and d_model = 768, the table holds 50,257 separate 768-dimensional vectors.

DATA By the Numbers (GPT-2 Small)
  • Vocabulary size: 50,257 distinct sub-words
  • Embedding width (d_model): 768 float32 coordinates
  • Embedding table: 38.6 million dedicated parameters
NOTE Why LLMs Struggle to Count Letters

Because BPE compresses character clusters into atomic token IDs before the model ever receives them, individual characters do not exist as independent entities in neural representations.

Positional Encoding: Injecting the Arrow of Time

THE MECHANISM

Self-attention treats sequences as unordered bags of words. Word order must be explicitly injected by adding a distinct harmonic fingerprint vector to each sequence position.

Fig 02 // Harmonic Frequency Spectrum
pkg-slim · 1.6MB 60 FPS WEBGPU
Harmonic Grid · Temporal Fingerprints

Rows represent dimensions; columns represent sequence positions 0–7. Each row halves the frequency of the row above it, widening wave periods. The cursor reads position 3's complete composite fingerprint.

positional.amx ↗

Choreography beats

  1. 1The coordinate matrix sweeps in — 8 positions across 4 sample dimensions.
  2. 2Geometric period doubling — rows display periods 3, 6, 12, 24, progressing from rapid oscillations to smooth gradients.
  3. 3Fingerprint extraction — the cursor isolates column 3, showing the exact additive vector injected into token 3.
Harmonic Wave Formulas & Modern RoPE

The original transformer computes fingerprints using interleaved sine and cosine waves of geometrically growing wavelengths: PE(pos, 2i) = sin(pos / 10000^(2i/d_model)). Smooth harmonic transitions allow the network to learn relative offsets as linear rotations.

SPECS Positional Wave Spectrum
  • Wavelength spectrum: 2π → 10,000 · 2π across dimensions
  • GPT-2 alternative: Learned absolute position vectors
  • Modern standard (Llama 3, Mistral): Rotary Embeddings (RoPE)
NOTE Rotary Embeddings (RoPE)

Instead of adding static vectors at the base, modern models rotate query and key vectors inside attention by an angle proportional to position, making dot products depend strictly on relative distance.

03

Self-Attention: The Dynamic Spotlight

THE MECHANISM

Every token projects into a Query (what it seeks), a Key (what it advertises), and a Value (what it provides). Softmax normalizes pairwise compatibility into weights that sum to 1.0.

Fig 03 // Scaled Dot-Product Attention
pkg-slim · 1.6MB 60 FPS WEBGPU
Coreference Spotlight · Softmax Distribution

The golden ring marks query token it. As it queries prior keys, softmax calculates weights for all tokens: 0.62 weight assigned to animal. The token absorbs animal's value vector to resolve its antecedent.

attention.amx ↗

Choreography beats

  1. 1Query activation — the pronoun it initiates a backward search across preceding tokens.
  2. 2Score computation — dot products are calculated between the query and all preceding keys.
  3. 3Softmax sharpening — scores pass through softmax; animal captures 62% of the total attention budget.
Mathematical Formalism & Attention Budgets

Attention(Q, K, V) = softmax(Q · Kᵀ / √d_k) · V

The score between query q and key k is scaled by dividing by √d_k (divisor = 8 for d_k = 64) to prevent dot products from saturating softmax gradients.

FORMULA Hyperparameters
  • Head dimension: d_k = 64 (divisor = 8)
  • Normalization: weights strictly sum to 1.0
  • Causal masking: prevents attending to future tokens
NOTE Attention Budget Dilation

Because softmax enforces a fixed probability budget of 1.0, expanding context to 128k tokens naturally dilutes individual weights, requiring specialized retrieval architectures like Needle-in-a-Haystack tuning.

Multi-Head Attention: Parallel Subspaces of Thought

THE MECHANISM

Language demands tracking grammar, semantics, and proximity at the same time. The model splits into h parallel heads in narrow subspaces, concatenating their findings through an output matrix.

Fig 04 // Parallel Attention Subspaces
pkg-slim · 1.6MB 60 FPS WEBGPU
Multi-Head Geometry · Parallel Specialization

Three heads analyze the same tokens in parallel. Head 1 specializes in syntax; Head 2 tracks semantic relations; Head 3 tracks sequential neighbours. Outputs drop into concatenated segments before fusing via linear mix WO.

multihead.amx ↗

Choreography beats

  1. 1Subspace division — parallel panels initialize for the same input sequence.
  2. 2Specialized attention maps — each head populates its distinct 3×3 attention matrix.
  3. 3Concatenation and fusion — head outputs align into a single continuous vector and project through WO.
Head Allocations & Induction Circuits

The computational budget remains constant: h heads × dk dims = dmodel. In GPT-2 Small, 12 heads of 64 dimensions each equal the 768-dimensional model width.

DATA Head Allocations Across Models
  • GPT-2 Small: 12 heads × 64 dims = 768
  • GPT-3 (175B): 96 heads × 128 dims = 12,288
  • Llama 3 (70B): 64 query heads / 8 KV heads (GQA)
NOTE Induction Heads in In-Context Learning

Circuits of two attention heads where Head A looks back for previous pattern occurrences and Head B copies the following token drive the few-shot learning capability observed in large models.

Feed-Forward Memory & The Residual Highway

THE MECHANISM

Attention mixes tokens together; the Feed-Forward Network transforms each token alone. It inflates into a 4 × dmodel associative memory chamber while residual skip connections preserve gradient flow.

Fig 05 // Residual Stream & FFN Expansion
pkg-slim · 1.6MB 60 FPS WEBGPU
The Skip Connections · Associative Recall

The platinum rail represents the residual stream. Skip connections arc over LayerNorm rings and sublayer blocks, rejoining with + accumulation markers. Signal widens d → 4d → d to retrieve associative memory.

feedforward.amx ↗

Choreography beats

  1. 1The residual rail — the unbroken carrier highway for token representations across layers.
  2. 2Sublayer execution — LayerNorm stabilizes magnitudes; attention mixes context; FFN expands 4× to recall facts.
  3. 3Additive skip junctions — outputs add back via skip connections (+) without replacing original signals.
Parameter Budgets & SwiGLU / MoE Architecture

Sublayers do not overwrite the flowing vector; they add to it: x ← x + Sublayer(LayerNorm(x)). The FFN accounts for two thirds of all parameters in every block.

DATA Parameter Distribution
  • Attention sublayer: 4 · d² parameters (Q, K, V, O)
  • Feed-forward sublayer: 8 · d² parameters (widen + narrow)
  • FFN proportion: ~66.7% of block parameter count
NOTE Modern SwiGLU & MoE

Modern models replace standard MLP with SwiGLU for smoother gating, or Mixture-of-Experts (MoE), which routes each token to 2 of 8 experts, tripling capacity at zero extra compute.

Stacking the Blocks: The Tower of Abstraction

THE MECHANISM

A complete model stacks N identical blocks. As token coordinates climb the tower, meaning refines: from surface syntax to world knowledge, culminating in next-token vocabulary logits.

Layer Climbing · Semantic Abstraction

Token vectors enter at the base and climb layer by layer. The internal state strip mutates as representations refine. At the summit, the vector fans out into the LM head to score the entire vocabulary.

pipeline.amx ↗

Choreography beats

  1. 1Prompt ingestion — embedded tokens enter the bottom of the transformer stack.
  2. 2Sequential block refinement — the vector climbs from Block 1 through Block N, acquiring richer context.
  3. 3Head projection — the final vector projects to the LM Head for next-token generation.
Layer Scaling & The KV Cache

Early layers model surface grammar; middle layers resolve coreference and facts; top layers synthesize next-token predictions. At the summit, the LM Head projects the 768-dimensional vector onto 50,257 vocabulary logits.

DATA Layer Scaling
  • GPT-2 Small: 12 layers · GPT-2 XL: 48 layers
  • Llama 3 70B: 80 layers · GPT-3: 96 layers
  • LM Head output: 50,257 to 128,256 logits per step
NOTE The KV Cache Optimization

During autoregressive generation, past key and value vectors are cached in GPU memory so generating each new token only requires computing Q, K, V for the single newest token (reducing compute from O(N³) to O(N)).

Synthesis & Architectural Evolution

THE COMPLETE CYCLE

01 The Unbroken Residual Rail

The continuous highway vector x flows unimpeded through hundreds of layers. Sublayers never overwrite—they only add small delta updates Δx = Sublayer(LN(x)), preserving clean gradient backpropagation across deep architectures.

02 Separation of Powers

Self-Attention serves as the spatial routing mechanism (mixing contextual coordinates across tokens), while the FFN serves as the associative fact repository (retrieving world knowledge for each token independently).
