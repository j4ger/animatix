01 / THE LANDSCAPE

A bowl with a steeper side.

The contours join points of equal loss. For L(x, y) = 2x² + y², curvature along x is twice the curvature along y.

02 / THE DIRECTION

Find uphill. Go the other way.

The gradient ∇L = (4x, 2y) points toward steepest increase. Subtract a scaled gradient to take a downhill step.

03 / THE PATH

Repeat, then see where you land.

Each update multiplies x by (1 − 4η) and y by (1 − 2η). Both shrink toward zero when 0 < η < 0.50. The motion connects discrete updates; it is not a rolling-ball simulation.
